Ruta a pie en Street View

Pon dos direcciones, ajusta la ruta y genera un video caminando por Street View.

1 · Clave de Google

Se guarda solo en este navegador. Necesita activadas: Maps JavaScript API, Geocoding API, Routes API y Street View Static API.

2 · Direcciones

– recorrido – caminando

¿Tú conoces otro camino? Toca el mapa para agregar un punto por donde pasar. Arrastra los puntos para moverlos y tócalos para quitarlos.

3 · Video

Guardar video

Mientras se graba, deja la página abierta y la pantalla encendida: el video se graba en tiempo real.

¿Cómo sacar la clave sin pagar?
  1. Entra a Google Maps Platform y crea un proyecto (pide tarjeta, pero no cobra dentro del cupo gratis).
  2. Activa Maps JavaScript API, Geocoding API, Routes API y Street View Static API.
  3. En Credenciales crea una clave de API. En "Restricciones de aplicaciones" elige Sitios web y pon la dirección de tu página (ej. https://tu-usuario.github.io/*). En "Restricciones de API" deja solo esas 4.
  4. Para no pagar nunca: en Cuotas de cada API pon un límite diario (por ejemplo 300 por día).
Pega tu clave de Google y dale «Guardar» para ver el mapa.
